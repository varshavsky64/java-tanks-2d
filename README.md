# Танки 2D

Аркада в духе Battle City на чистой Java + Swing. Внешних зависимостей и файлов ресурсов нет:
графика рисуется примитивами Graphics2D, звук синтезируется в память при старте.

Пакет: `io.github.varshavsky64.tanks`

## Запуск

```bash
mvn compile
mvn exec:java
```

Или собрать jar:

```bash
mvn package
java -jar target/game-tanks-2d-1.0.0.jar
```

Из IDEA: запустить `io.github.varshavsky64.tanks.Main`.

| Стрелки или WASD   | движение                 |

## Правила

Нужно уничтожить 20 вражеских танков на уровне и не дать разрушить базу-орла внизу карты.
Игра заканчивается, если разбита база или кончились жизни. Свой снаряд тоже ломает
стену вокруг базы — стрелять в её сторону опасно.

Один выстрел выбивает пробоину шириной ровно в танк и глубиной в одну клетку, поэтому
блок стены пробивается двумя попаданиями.

### Типы врагов

| Тип     | Цвет      | Особенность                    | Очки |
|---------|-----------|--------------------------------|------|
| Обычный | серый     | ничего особенного              | 100  |
| Быстрый | голубой   | высокая скорость               | 200  |
| Мощный  | фиолетовый| быстрый снаряд, скорострельный | 300  |
| Тяжёлый | жёлтый→красный | выдерживает 4 попадания   | 400  |

Каждый 4-й, 11-й и 18-й враг — «бонусный», мигает красным и при уничтожении оставляет бонус.

### Бонусы

| Бонус   | Эффект                                    |
|---------|-------------------------------------------|
| Звезда  | улучшение оружия (скорость снаряда → два снаряда → пробитие брони) |
| Каска   | неуязвимость на 10 секунд                 |
| Граната | уничтожает всех врагов на поле            |
| Танк    | +1 жизнь                                  |
| Лопата  | стена вокруг базы становится бронёй на 15 с |
| Часы    | враги замирают на 8 секунд                |

## Ландшафт

Кирпич разрушается снарядом, броня — только полностью прокачанным оружием. Вода не пускает
танки, но пропускает снаряды. Кусты рисуются поверх танков и прячут их. По льду танк скользит.

## Звук

`SoundEngine` синтезирует все 12 эффектов в память при запуске (меандр, синус, сглаженный шум)
и подмешивает активные голоса в одну звуковую линию в фоновом потоке — поэтому звуки
накладываются друг на друга, чего не умеет одиночный `Clip`. Если звуковой карты нет,
движок молча отключается. `World` работает через интерфейс `Audio`, так что логику можно
прогонять без звука (`Audio.SILENT`).

Там же синтезируется фоновая музыка — «Калинка» (И. Ларионов, 1860) в аранжировке под чиптюн
восьмибитных консолей: мелодию ведёт узкий импульс, на повторах ей вторит меандр в терцию,
треугольник непрерывно разбирает аккорд восьмыми, шум и низкий свип работают за ударные.
Трек собирается в один буфер и крутится по кругу на пониженной громкости. Клавиша `N`
выключает только музыку, `M` — вообще весь звук.

## Структура

```
Main         точка входа
GamePanel    игровой цикл на Swing-таймере и ввод
Renderer     вся отрисовка, палитра и панель со счётом
World        состояние уровня и правила взаимодействий
Level        карты (пишутся в сетке 22x16, разворачиваются в 44x32 клетки)
Tank         база для танков: движение с выравниванием по сетке, стрельба
PlayerTank   управление игроком и прокачка
EnemyTank    типы врагов и их ИИ
SoundEngine  синтез и микширование звука; Audio / Sound — интерфейс и список эффектов
Bullet / Explosion / PowerUp / ScorePopup / Entity / Direction / TileType / Input / GameState
```

Геометрия: клетка 16 px, поле 44×32 клетки (704×512), танк 32 px, панель 150 px.

Новый уровень добавляется одной строковой картой в `Level.MAPS`: символы
`.` пусто, `#` кирпич, `S` броня, `W` вода, `T` кусты, `I` лёд, `B` база.
Размер карты проверяется при загрузке, опечатка в длине строки даст понятную ошибку.
